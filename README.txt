# GastTrackPay

GastTrackPay is a blockchain-based decentralized application (dApp) for secure and transparent fuel tracking and payment management. The platform allows users to track fuel consumption, automate payments, and ensure the integrity of transaction records using blockchain technology.

## Features

- Blockchain-powered transaction ledger
- Smart contract integration for automated payments
- Role-based access control: Admin, Fuel Provider, Consumer
- Fuel usage tracking and reporting
- Wallet integration for blockchain transactions
- Frontend interface for interacting with the smart contracts

## Tech Stack

- Blockchain Platform: Ethereum (Local Blockchain via Ganache)
- Smart Contracts: Solidity
- Development Framework: Truffle
- Frontend: HTML, CSS, JavaScript (or React if applicable)
- Backend (if used): Node.js / Express.js
- Wallet: MetaMask

## Prerequisites

Before setting up the project, ensure the following are installed on your system:

- Node.js and npm
- Truffle (`npm install -g truffle`)
- Ganache (Desktop or CLI)
- MetaMask browser extension
- Git
